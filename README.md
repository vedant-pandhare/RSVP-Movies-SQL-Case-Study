# 🎬 RSVP Movies – SQL Data Analysis

## 📌 Project Overview
This project focuses on analyzing IMDb movie data for RSVP Movies using MySQL. The objective is to explore movie trends, ratings, genres, production companies, directors, and actors to generate meaningful business insights.

## 🛠️ Tools & Technologies
- MySQL
- SQL
- MySQL Workbench

## 📂 Project Files
- `IMDB+dataset+import (1).sql` – IMDb dataset import script.
- `RSVP_Movies_Solved.sql` – SQL solutions for 29 business questions.
- `RSVP_Movies_Executive_Summary.pdf` – Project findings and recommendations.

## 🔍 Key Analysis
- Movie release trends and yearly analysis.
- Genre-wise movie performance.
- Average movie ratings and duration.
- Top-rated movies.
- Production company analysis.
- Director and actor performance.
- Revenue and ranking analysis.

## 💡 SQL Concepts Used
- SELECT, WHERE, GROUP BY, HAVING
- Joins and Subqueries
- Aggregate Functions
- CASE Statements
- UNION ALL
- Window Functions
- ROW_NUMBER()

## 📊 Business Insights
Analyzed movie industry data to identify trends, audience preferences, and production performance to support business decision-making.
